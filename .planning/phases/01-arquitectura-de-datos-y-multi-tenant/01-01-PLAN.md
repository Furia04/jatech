# Plan 01-01: Migración SQL y Políticas RLS para Supermercado Multi-Tenant

## Objective
Diseñar y escribir el script SQL de migración en Supabase (`supabase/migrations/20261007_market_schema.sql`) para establecer el esquema relacional dedicado de supermercado (`market_*`), la extensión de roles en `users` y las políticas Row Level Security (RLS) estrictas aisladas por `shop_id`.

## Context
- `01-CONTEXT.md`: Tablas dedicadas `market_*`, columna `market_role` en `users`, turnos asociados a `(shop_id, cashier_id)` y `market_mp_configs` protegido.
- `01-RESEARCH.md`: Modelado con `NUMERIC(12,3)` para stock/pesables, índice compuesto único `(shop_id, barcode)` y funciones RLS reutilizando `public.get_current_shop_id()`.

<task id="01-01-02">
<title>Habilitar Row Level Security (RLS) y definir políticas multi-tenant</title>
<action>
En el mismo script `supabase/migrations/20261007_market_schema.sql`, añadir:
1. Función auxiliar de verificación de rol administrador de supermercado:
   ```sql
   CREATE OR REPLACE FUNCTION public.is_market_admin()
   RETURNS BOOLEAN AS $$
     SELECT (
       public.is_superadmin()
       OR EXISTS (
         SELECT 1 FROM public.users
         WHERE id = auth.uid()
           AND (role = 'owner' OR market_role = 'admin')
       )
     );
   $$ LANGUAGE sql STABLE SECURITY DEFINER SET search_path = public;
   ```
2. Habilitar RLS en las 8 tablas:
   `ALTER TABLE public.market_categories ENABLE ROW LEVEL SECURITY;`
   `ALTER TABLE public.market_products ENABLE ROW LEVEL SECURITY;`
   `ALTER TABLE public.market_stock_movements ENABLE ROW LEVEL SECURITY;`
   `ALTER TABLE public.market_cash_shifts ENABLE ROW LEVEL SECURITY;`
   `ALTER TABLE public.market_cash_movements ENABLE ROW LEVEL SECURITY;`
   `ALTER TABLE public.market_sales ENABLE ROW LEVEL SECURITY;`
   `ALTER TABLE public.market_sale_items ENABLE ROW LEVEL SECURITY;`
   `ALTER TABLE public.market_mp_configs ENABLE ROW LEVEL SECURITY;`
3. Políticas de acceso:
   - Políticas estándar multi-tenant para las tablas operativas:
     `USING (shop_id = public.get_current_shop_id() OR public.is_superadmin())`
     `WITH CHECK (shop_id = public.get_current_shop_id() OR public.is_superadmin())`
   - D-04: Política restrictiva para `market_mp_configs`:
     Lectura y modificación permitida únicamente si `(shop_id = public.get_current_shop_id() AND public.is_market_admin()) OR public.is_superadmin()`.
</action>
