# Plan 01-02: Contratos de Tipos TypeScript y Servicios Supabase para Supermercado

## Objective
Definir los tipos TypeScript estrictos en `src/types/market.ts` y crear la capa de servicios de datos en `src/lib/supabase/market-services.ts` para conectar la aplicación Next.js con el nuevo esquema de supermercado bajo aislamiento multi-tenant.

## Context
- `01-01-PLAN.md`: Establece el esquema de tablas SQL `market_*`.
- `src/types/index.ts`: Tipos base existentes (`Shop`, `UserProfile`).
- `src/lib/supabase/client.ts` y `server.ts`: Clientes existentes de conexión a Supabase.

## Tasks

<task id="01-02-01">
<title>Definir los contratos de tipos en src/types/market.ts</title>
<action>
Crear el archivo `src/types/market.ts` conteniendo los tipos e interfaces para:
1. `MarketRole`: `'cashier' | 'manager' | 'admin'`
2. `UnitType`: `'unit' | 'kg' | 'g' | 'l' | 'm'`
3. `StockMovementType`: `'sale' | 'purchase' | 'adjustment' | 'waste' | 'cancellation'`
4. `CashShiftStatus`: `'open' | 'closed'`
5. `CashMovementType`: `'income' | 'expense'`
6. `MarketPaymentMethod`: `'efectivo' | 'tarjeta_debito' | 'tarjeta_credito' | 'transferencia' | 'mercadopago_qr' | 'mixto'`
7. `MarketCategory`: `id`, `shop_id`, `name`, `description`, `created_at`
8. `MarketProduct`: `id`, `shop_id`, `category_id`, `barcode`, `name`, `brand`, `cost_price`, `sale_price`, `stock`, `min_stock`, `is_weighable`, `unit_type`, `active`, `created_at`, `updated_at`, con `category?: MarketCategory`
9. `MarketStockMovement`: `id`, `shop_id`, `product_id`, `user_id`, `quantity`, `previous_stock`, `new_stock`, `type`, `reason`, `created_at`
10. `MarketCashShift`: `id`, `shop_id`, `cashier_id`, `status`, `initial_cash`, `expected_cash`, `actual_cash`, `difference`, `total_sales_amount`, `notes`, `opened_at`, `closed_at`, con `cashier?: { full_name: string; email: string }`
11. `MarketCashMovement`: `id`, `shop_id`, `shift_id`, `user_id`, `type`, `amount`, `reason`, `created_at`
12. `MarketSale`: `id`, `shop_id`, `shift_id`, `cashier_id`, `ticket_number`, `total_amount`, `payment_method`, `payment_details`, `amount_paid`, `change_returned`, `status`, `created_at`, con `items?: MarketSaleItem[]`
13. `MarketSaleItem`: `id`, `shop_id`, `sale_id`, `product_id`, `barcode`, `product_name`, `quantity`, `unit_price`, `total_price`, `created_at`
14. `MarketMPConfig`: `id`, `shop_id`, `access_token`, `public_key`, `pos_id`, `user_id_mp`, `is_active`, `created_at`, `updated_at`
Exportar todos los tipos y asegurar compatibilidad con TypeScript estricto.

<task id="01-02-02">
<title>Implementar capa de servicios Supabase en src/lib/supabase/market-services.ts</title>
<action>
Crear el archivo `src/lib/supabase/market-services.ts` utilizando el cliente Supabase de `@/lib/supabase/client`:
1. Funciones de Catálogo:
   - `fetchMarketCategories()`: Obtiene categorías de la tienda activa.
   - `fetchMarketProducts(options?: { search?: string; categoryId?: string; activeOnly?: boolean })`: Consulta productos con búsqueda rápida por código de barras o texto.
   - `fetchMarketProductByBarcode(barcode: string)`: Búsqueda exacta de un producto por código de barras.
2. Funciones de Turnos de Caja:
   - `getActiveCashShift(cashierId?: string)`: Consulta si el cajero actual tiene un turno abierto.
   - `openCashShift(initialCash: number, notes?: string)`: Abre un nuevo turno de caja.
   - `closeCashShift(shiftId: string, actualCash: number, notes?: string)`: Cierra el turno registrando arqueo.
3. Funciones de Configuración MP:
   - `getMarketMPConfig()`: Obtiene la configuración de Mercado Pago para la tienda activa.
   - `saveMarketMPConfig(config: Partial<MarketMPConfig>)`: Guarda o actualiza tokens de MP.
4. Exportar utilidades de permisos para verificar si el usuario es `cashier`, `manager` o `admin`.
</action>
