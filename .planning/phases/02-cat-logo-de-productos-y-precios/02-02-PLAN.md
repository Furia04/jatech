# Plan 02-02: Modal de Producto con Márgenes y Sistema de Importación/Exportación CSV

## Objective
Desarrollar el modal de alta/edición de productos con cálculo bidireccional reactivo de costo/margen/precio y clasificación de pesables (`D-03`, `CAT-02`), e implementar el módulo de importación y exportación masiva CSV con lógica de upsert inteligente (`D-04`, `CAT-04`).

## Context
- `02-CONTEXT.md`: Cálculo de margen en tiempo real, tipo de unidad (unidad vs pesable), carga masiva CSV con plantilla y upsert.
- `src/lib/supabase/market-services.ts`: CRUD de productos.

## Tasks

<task id="02-02-01">
<title>Crear el modal de producto con cálculo bidireccional y clasificación de pesables</title>
<action>
1. D-03, CAT-02: Crear `src/components/market/product-modal.tsx` con:
   - Campos: Código de barras (con botón para autogenerar código interno si es producto casero), Nombre, Marca, Categoría (selector y opción rápida de crear nueva), Tipo de venta (Unidad vs Pesable por Kg / Fraccionable).
   - D-03: Sección de Precios y Rentabilidad:
     - Input Costo ($)
     - Input Margen deseado (%)
     - Input Precio de Venta ($)
     - Cálculo reactivo: si se modifica Costo o Margen %, se autocalcula Precio de Venta (`costo * (1 + margen/100)`); si se modifica Precio de Venta, se autocalcula Margen % (`((precio - costo) / costo) * 100`).
     - Alerta visual en tiempo real si el margen resulta negativo o el precio es menor al costo.
   - Campo Stock inicial y Stock mínimo de alerta.
   - Guardado mediante `createMarketProduct` o `updateMarketProduct`.
</action>

</verify>
<done>
Modal de producto completamente funcional con cálculo bidireccional y soporte para pesables.
</done>
</task>
